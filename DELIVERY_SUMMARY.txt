⚡ QUICK START (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ADD TO <HEAD> OF YOUR HTML:
   <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
   <link rel="stylesheet" href="/static/css/responsive.css">
   <link rel="stylesheet" href="/static/css/responsive-integration.css">

2. ADD BEFORE </BODY>:
   <script src="/static/js/mobile-nav.js"></script>

3. UPDATE YOUR LAYOUT:
   <div class="app-container">
       <nav class="top-header"><!-- header content --></nav>
       <aside class="sidebar"><!-- navigation --></aside>
       <main class="main-content">
           <div class="content-area"><!-- your content --></div>
       </main>
   </div>

4. USE RESPONSIVE CONTAINERS:
   <div class="stats-grid"><!-- cards --></div>
   <div class="table-responsive"><table><!-- data --></table></div>
   <form><div class="form-row"><!-- fields --></div></form>

5. TEST ON MOBILE:
   Press F12 (DevTools) → Device mode → Test

That's it! Your app is now responsive! 🎉

   Without this, mobile won't work properly:
   <meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">

2. CSS LINK ORDER MATTERS
   Order must be:
   1. Your existing style.css
   2. responsive.css
   3. responsive-integration.css

3. JAVASCRIPT REQUIRED
   mobile-nav.js creates the hamburger menu automatically
   Must be included before closing </body> tag

4. FONT SIZES
   Use 16px minimum on inputs to prevent iOS auto-zoom
   Responsive CSS handles this automatically

5. TOUCH TARGETS
   All buttons must be 44px+ (enforced by CSS)
   Ensure proper spacing between interactive elements
